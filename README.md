# CRISP-DM Data Mining: Regression & Classification

## End-to-End Data Mining Using the CRISP-DM Methodology

An applied data-mining project demonstrating the complete **CRISP-DM workflow** through two supervised learning problems:

- **Regression:** House price prediction
- **Classification:** Chronic kidney disease prediction

The project focuses not only on model training, but on the complete analytical workflow — from understanding the data and preparing features to model evaluation, visualization, and interpretation.

---

## Project Overview

The **CRISP-DM (Cross-Industry Standard Process for Data Mining)** framework provides a structured approach to solving data-mining problems.

This project applies the workflow to two fundamentally different prediction tasks:

| Task | Dataset | Problem | Target |
|---|---|---|---|
| Regression | Kaggle House Prices | Predict a continuous value | `SalePrice` |
| Classification | UCI Chronic Kidney Disease | Predict a binary class | `ckd` / `notckd` |

### CRISP-DM workflow

```text
Business Understanding
        ↓
Data Understanding
        ↓
Data Preparation
        ↓
Feature Engineering
        ↓
Modeling
        ↓
Evaluation
        ↓
Result Analysis
**Tech stack:** pandas, numpy, scikit-learn, matplotlib, seaborn'''
